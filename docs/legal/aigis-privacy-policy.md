# Aigis Privacy Policy

Last updated: 26 November 2026

Aigis is a private, non-commercial Discord bot for a single server of friends. It is run by that server's owner ("we").

## What is stored today

- Your Discord user ID, with the language and time zone you choose.
- The server ID, its default language and the channel IDs set up for Aigis.
- Technical logs, such as errors and which command failed.

## Planned features

These are not all available yet. As they are added, Aigis may also handle:

- **Activity you submit:** video links and ratings, game scores and a link to the screenshot message, availability schedules, games you own, daily characters and card votes.
- **Message content:** used for chat replies, translation, finding your score screenshot and an occasional unprompted reply. Aigis does not store or log message text, though it keeps short chat context in memory for a while.
- **AI processing:** text needed for chat and translation is sent to Cloudflare Workers AI. You will be able to exclude your messages from translation and unprompted replies.
- **Music:** your search terms and links are used to fetch audio from YouTube.

We will update this policy if what is handled changes.

## How it is used and shared

Data is used only to run Aigis's features. It is not sold or used for advertising. Other members of the server can see what a feature displays, such as leaderboards. Discord, and the providers named above, process data under their own policies.

## Where and how long

Data is stored on equipment controlled by the server owner. It is kept until it is no longer needed or you ask for it to be deleted. Backup copies may keep deleted data for a short period.

## Your choices

Using Aigis is optional. To see, correct or delete your data, message the server owner on Discord.
